FAQ

The questions that matter before you trust it with sent mail.

Does SentRules send duplicate messages?

SentRules is built around a single send operation and a send-operation journal. The accepted Outlook build was smoke-tested by sending exactly once, filing the sent copy, and leaving both Sent Items and Drafts clean.

What happens if the destination folder is renamed?

SentRules resolves the destination by live Microsoft folder identity and rebuilds its current path. A renamed parent or folder can still be recognized without relying on stale display text.

What if the folder was deleted?

SentRules fails closed. It sends the message once, skips unsafe filing, keeps the sent copy safe in Sent Items, and tells you not to resend.

What if two saved rules match the same message?

If they point to different destinations, SentRules reports a conflict and moves nothing. It will not guess which folder you meant.

Can it clean up old Sent Items?

Yes. Advanced previews historical Sent Items against your saved rules, shows matches, conflicts, blocked destinations, and proof totals, then moves only the unambiguous messages you approve.

Is SentRules a Microsoft product?

No. SentRules is an independent Outlook add-in. Microsoft and Outlook are trademarks of their respective owners.
